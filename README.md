## 🚀 Projects

### Week 1: Python CLI Calculator (`Week1/Calculator.py`)
An interactive command-line calculator supporting basic arithmetic operations with input validation and exception handling.

#### Features:
- Supports `+`, `-`, `*`, and `/` operations.
- Graceful handling of invalid inputs (`ValueError`) and zero division (`ZeroDivisionError`).
- Interactive loop with exit option (`q`).

#### Usage:
```bash
python Week1/Calculator.py
```

## 🛠️ Getting Started

### Prerequisites
- Python 3.10+
- (Optional) Virtual environment:
  ```bash
  python -m venv .venv
  # Windows:
  .venv\Scripts\activate
  # Linux/macOS:
  source .venv/bin/activate
  ```
